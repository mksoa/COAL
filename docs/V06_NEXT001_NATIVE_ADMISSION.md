# COAL V0.6 candidate — native original-operation admission (SOURCE ONLY)

Extends the existing V0.4 `OneUseAdmissionPort` and V0.5 carrier. A Git-native `refs/heads/coal/admissions/<sha256>` is derived from domain, repository, exact mission, immutable original PRE-ACT epoch and ONE OF SIX original GLOW R12 operation IDs. **The ref name deliberately excludes any source successor/identity/carrier digest**: a new source digest cannot mint a fresh admission for an already attempted operation. No arbitrary operation key or ref name is accepted.

A separately injected, fixed-COAL writer performs one `POST /git/refs` for that fixed admission ref pointing only at the already shape-checked COAL-local carrier commit. Original 201 POST response (headers' request-id, body hash and safe body, timestamps) is retained in a `Receipt`; separate read-only native GET must report the exact ref/target before returning a bounded `FIRST_CONSUMED` to the prior `reserve_with_admission` seam. Any unexpected HTTP status, 422, 403, divergent body, readback failure or lost ACK returns UNKNOWN, no ref POST retry, no original effect. A second process targeting the same operation competes on the **same native Git ref** rather than on a process-local lock; synthetic tests are not live native contention proof. No CLI or runner invokes this adapter by default.

Security ceiling: GitHub ref CREATE is not an independently admin-proof, permanently append-only witness. An administrator/principal with UPDATE or DELETE ability may mutate the admission ref. It is explicitly not a qualified external W038 witness or permission boundary. Source shape checks and returned FIRST_CONSUMED cannot authorize H0/M0, issuer identity or any effect. Before original NEXT-001, a custodial issuer must be independently authenticated and limited, the external monotone W038 witness and Claim→Slot native evidence must be qualified, and a distinct owner H0 plus each JIT M0 must exist. Do not spend original six attempts in tests.

No new workflow, test campaign, public execution endpoint, product framework or release.
